N E B U L A D E C K

Set up your screen

An always-on touch display for AI agents on the Panlee SC01 Plus. It lives on your WiFi; your agents talk to it over the local network.

This browser can't use Bluetooth from a web page. Use Chrome or Edge on Android, macOS, Windows or Linux. On iPhone or iPad, open this page in the Bluefy browser.

1 · Find your NebulaDeck

Keep the screen showing its QR code, then pick NebulaDeck in the Bluetooth dialog.

2 · Choose your network

Connected to the screen

    The password goes straight to the screen over Bluetooth and is stored only on the device.

    3 · You're online

    Your NebulaDeck is on at nebuladeck.local (). In a few seconds it switches to “Agent not connected”.

    Check it from your computer with curl http://nebuladeck.local/api/info, then set up your agent.

    If nebuladeck.local doesn't resolve on your computer, use the IP instead: export NEBULADECK_HOST=IP. To change network later, hold the screen for 5 seconds.

    This browser can't talk to USB serial devices. Use Chrome or Edge on a desktop.

    1 · Put the board in download mode

    1. Unplug the board, then connect it with a USB-C data cable.
    2. On the DEBUG header, jumper BOOT to GND.
    3. Press RST. The screen may stay dark.

    If the board is already running NebulaDeck, the install may work without this. Try it first; if it can't connect, do the steps above.

    2 · Install

    The stable release. Updates arrive over WiFi when a new version is released.

    Pick the usbmodem / Espressif port in the browser dialog. Installing replaces whatever is on the board.

    3 · Finish

    1. Remove the BOOT jumper and press RST. The screen shows a welcome QR code.
    2. Connect it to WiFi: continue with Connect to WiFi.

    Claude Code · live status while chatting (optional)
    
      
    Hooks make the screen show “Claude connected” with “Thinking…”, “Running a command…”, “Needs you” and “Ready” in every session, even without a task. Each hook is a background curl that sends only the event name, never your prompts or files.
    
      
    Easiest: with the skill installed, ask Claude:
    
      
    Install the NebulaDeck hooks from the nebuladeck skill's hooks.json into my ~/.claude/settings.json.
    
      
    Or merge hooks.json into ~/.claude/settings.json yourself.
    
    
    

    
    
      
    Other agents
    
      
    Anything that can run curl can drive the screen. Paste this into your agent's instructions (AGENTS.md, rules, system prompt):
    
      
    A NebulaDeck status screen is on my local network at http://nebuladeck.local/api (JSON over HTTP, use curl -m 3, ignore failures).
- Starting a multi-step task: POST /api/state {"status":"working","title":"...","project":"..."}
- Milestones: POST /api/msg {"text":"...","level":"info|warn|error"}
- Need a decision: POST /api/ask {"id":"q1","prompt":"...","options":["Yes","No"],"timeout":120}, then poll GET /api/answer?id=q1 every second until it is not "pending" ("answered:<option>" or "cancelled"; then ask in chat)
- Finished (always, even on failure): POST /api/done {"summary":"..."}
Keep titles under 60 characters, plain text, no secrets.
    
      
    Full API: docs/PROTOCOL.md.
