N E B U L A D E C K

Flash your screen

An always-on touch display for AI agents on the Panlee SC01 Plus. This page installs the latest firmware straight from your browser.

This browser can't talk to USB serial devices. Use Chrome or Edge on a desktop.

1 · Put the board in download mode

  1. Unplug the board, then connect it with a USB-C data cable.
  2. On the DEBUG header, jumper BOOT to GND.
  3. Press RST. The screen may stay dark.

If the board is already running NebulaDeck, the install may work without this. Try it first; if it can't connect, do the steps above.

2 · Install

Pick the usbmodem / Espressif port in the browser dialog. Installing replaces whatever is on the board.

3 · Finish

  1. Remove the BOOT jumper and press RST. You should see the nebula and “Agent not connected”.
  2. Install the CLI so agents can use it: npm i -g nebuladeck, then nebuladeck state working "Hello".
