NEBULADECK

Set up your screen

An always-on touch display for AI agents on the Panlee SC01 Plus or SC01. It lives on your WiFi; your agents talk to it over the local network.

This browser can't use Bluetooth from a web page. Use Chrome or Edge on Android, macOS, Windows or Linux. On iPhone or iPad, open this page in the Bluefy browser.

1 · Find your NebulaDeck

Keep the screen showing its QR code, then pick NebulaDeck in the Bluetooth dialog.

2 · Choose your network

Connected to the screen

    The password goes straight to the screen over Bluetooth and is stored only on the device.

    3 · You're online

    Your NebulaDeck is on at nebuladeck.local (). In a few seconds it switches to “Agent not connected”.

    Next, set up your agent. If nebuladeck.local doesn't work on your computer, set up your agent with the IP instead.

    To change network later, tap the logo on the screen → Forget WiFi.

    This browser can't talk to USB serial devices. Use Chrome or Edge on a desktop.

    1 · Connect the board

    Plug the board in with a USB data cable. Both boards work with the same button below: it detects which one you have.

    • SC01 (ESP32): nothing else to do, it switches to install mode by itself.
    • SC01 Plus (ESP32-S3): usually works as is too. If the install can't connect, put it in download mode: on the DEBUG header jumper BOOT to GND, then press RST (the screen may stay dark).

    2 · Install

    The stable release. Updates arrive over WiFi when a new version is released.

    Be patient: installing takes a couple of minutes, and the Erasing step can sit still for a while before progress moves. That's normal. Keep this tab open and the cable connected until it says it's done.

    In the browser dialog pick the board's port: usbmodem / Espressif for the SC01 Plus, usbserial / CP210x or CH340 for the SC01. Installing replaces whatever is on the board.

    3 · Finish

    1. If you used the BOOT jumper, remove it and press RST. The screen shows a welcome QR code.
    2. Connect it to WiFi: continue with Connect to WiFi.

    Device address

    Where your agents reach the screen. Keep nebuladeck.local, or use the IP from the screen's logo menu if .local names don't work on your network. Everything below updates as you type.

    From a terminal:

    Claude Code · skill

    The skill tells Claude when to update the screen and how to ask you questions on it. Run this in a terminal, then start a new Claude Code session:

    mkdir -p ~/.claude/skills/nebuladeck && cd ~/.claude/skills/nebuladeck && \
  curl -fsSL {{BASE}}SKILL.md{{SED}} > SKILL.md && \
  curl -fsSL {{BASE}}hooks.json{{SED}} > hooks.json

    Or download SKILL.md into ~/.claude/skills/nebuladeck/.

    Optional · live status while chatting

    Hooks show “Claude connected” with “Thinking…”, “Running a command…”, “Needs you” and “Ready” in every session. Each one is a background curl that sends only the event name. With the skill installed, ask Claude:

    Install the NebulaDeck hooks from the nebuladeck skill's hooks.json into my ~/.claude/settings.json.

    Or merge hooks.json into ~/.claude/settings.json yourself.

    Add the instructions to your global ~/.codex/AGENTS.md (or to AGENTS.md in one repo):

    mkdir -p ~/.codex && cat >> ~/.codex/AGENTS.md <<'EOF'

{{INSTR}}
EOF

    Codex runs commands in a sandbox with networking off by default, so the curl calls fail silently. Allow it in ~/.codex/config.toml:

    [sandbox_workspace_write]
network_access = true

    Cursor

    For every project: Cursor Settings → Rules → User Rules, and paste:

    {{INSTR}}

    Or for one project, from its folder:

    mkdir -p .cursor/rules && cat > .cursor/rules/nebuladeck.mdc <<'EOF'
---
description: NebulaDeck desk status screen
alwaysApply: true
---
{{INSTR}}
EOF

    The agent runs the curl commands in Cursor's terminal; approve them, or allow curl in your auto-run settings.
